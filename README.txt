ESYSERVE — Full Digital Solutions Pricing Catalogue
====================================================

PRICING MODEL
-------------
Static Portfolio: Lifetime-only software pricing.
Dynamic Portfolio: Yearly or lifetime software pricing. Employee/user capacity is based on the selected hosting plan and server resources.
Full Management System: Yearly software/support pricing.
Complete Workforce: Yearly software/support pricing.

IMPORTANT:
Domain and hosting are EXTERNAL for EVERY plan.
They are never included in the software price.

External / separately quoted items can include:
- Domain registration and renewal
- Hosting / VPS / cloud / dedicated server
- SMS / WhatsApp messaging
- Payment gateways
- Special infrastructure
- Custom third-party integrations
- Physical attendance hardware

DOMAIN & HOSTING
----------------
Domain and hosting/server are EXTERNAL for EVERY plan. They are never included in the software pricing.

WORKFORCE HARDWARE
------------------
Physical biometric / face recognition / RFID machines are NOT included.
Installation/configuration: ₹3,000–₹7,500 per location.
Hardware is quoted separately by model and quantity.


FINAL STRUCTURE
One complete ESYSERVE website contains all four solution levels in the same Solutions, Pricing, Compare, Features, FAQ and Contact sections. Pricing is displayed only in the Pricing section. The Live Estimate area does not calculate or display prices. Static is lifetime-only; Dynamic supports yearly and lifetime; Management and Workforce are yearly. Domain and hosting are external for all plans.
