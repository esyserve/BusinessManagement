PRICING MODEL
-------------
Static Portfolio: Lifetime-only software pricing.
Dynamic Portfolio: Yearly software/support pricing.
Full Management System: Yearly software/support pricing.
Complete Workforce: Yearly software/support pricing.

IMPORTANT:
Domain and hosting are EXTERNAL for EVERY plan.
They are never included in the software price.

External / separately quoted items can include:
- Domain registration and renewal
- Hosting / VPS / cloud / dedicated server
- SMS / WhatsApp messaging
- Payment gateways
- Special infrastructure
- Custom third-party integrations
- Physical attendance hardware
